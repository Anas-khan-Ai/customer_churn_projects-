# Customer Churn Prediction & Retention Analysis System

## Overview
This project is an AI-powered Customer Churn Prediction and Retention Analysis System built using Python, Streamlit, Pandas, Plotly, and Machine Learning.

The system analyzes customer data, predicts customer churn, provides business insights, and helps organizations improve customer retention strategies through predictive analytics.

## Features
- Customer Churn Prediction
- Interactive Dashboard
- KPI Monitoring
- Customer Retention Analysis
- Business Insights
- Data Visualization
- Machine Learning Model
- Download Reports

## Technologies Used
- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Scikit-learn
- Random Forest

## Business Value
- Identify customers likely to leave
- Improve customer retention
- Support data-driven decision making
- Reduce customer churn
- Increase customer loyalty
